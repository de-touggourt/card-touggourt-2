# مشروع البطاقات المهنية - مديرية التربية لولاية توقرت (cad-touggourt)

مشروع موحد وخفيف لإنشاء وطباعة البطاقات المهنية للموظفين، والتحكم المركزي عبر لوحة القيادة، مع الربط المباشر والحي بقاعدة بيانات **Supabase** وحفظ الصور على **Cloudflare R2**.

## 🚀 محتويات الحزمة الإنتاجية (الملفات الأساسية فقط)

| الملف | الوظيفة |
| :--- | :--- |
| `index.html` | الواجهة الرئيسية للنظام: طباعة البطاقات، بحث الموظفين، ودخول مديري المؤسسات |
| `card.html` | نسخة مطابقة لـ `index.html` لضمان عمل كافة الروابط المباشرة |
| `dashboard_card.html` | لوحة القيادة المركزية للإدارة: إحصائيات حية، سجل القيد، الترقيم المتسلسل، التعديلات |
| `supabase_config.js` | محرك الربط والاتصال الآمن بـ Supabase (بيانات حية مباشرة بدون تخزين محلي نهائياً) |
| `institutions_touggourt.js` | القائمة الرسمية لجميع المؤسسات التعليمية بولاية توقرت وبياناتها الجغرافية |
| `cf_photos_map.js` | خريطة روابط صور الموظفين على Cloudflare R2 |
| `logo_downloaded.png` | الشعار الرسمي لمديرية التربية لولاية توقرت |
| `ministry_logo_perfect_circle.png` | الشعار الرسمي لوزارة التربية الوطنية |
| `supabase_complete_schema.sql` | ملف SQL الشامل لقاعدة البيانات: الجداول، التريغرز، وسياسات الحماية (RLS) |

---

## ⚡ مميزات النسخة الجديدة

1. **انفصال كامل عن Firebase:** تم استئصال أي كود أو مكتبة أو استعلام يخص Firebase تماماً.
2. **بيانات حية 100% (Zero Caching):** لا يوجد أي تخزين محلي (localStorage أو localforage) لبيانات الموظفين، كل استعلام يأتي مباشرة وحياً من Supabase (9,074 موظفاً).
3. **حل مشكلة عدد الموظفين:** تم حذف ملف `personnel_touggourt.js` القديم (الذي كان يفرض الرقم 9055)، وأصبحت لوحة القيادة تعرض الرقم الحقيقي الدقيق من السيرفر وهو **9074**.
4. **إصلاح تسجيل دخول المدير:** يعمل زر تسجيل دخول المديرين الآن بسلاسة ويتحقق من جدول `base-touggourt` في Supabase مع ربط المؤسسة بشكل فوري ودقيق.
5. **حماية أمان صارمة (RLS):** الجداول محمية بسياسات RLS، ولا يمكن قراءة كلمات المرور الحساسة أو التلاعب بها من الواجهة الأمامية.
6. **سير عمل الصور (Cloudflare R2):** ظل منطق رفع الصور إلى Cloudflare كما هو بدون أي تغيير، ويتم فقط حفظ رابط الصورة النهائي في الحقل `photo_url` داخل Supabase.
