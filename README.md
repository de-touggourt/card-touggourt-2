# منظومة البطاقة المهنية الرقمية | مديرية التربية لولاية توقرت
## النسخة السحابية المباشرة (Cloud-Native Online Deployment)

تم إعداد هذا المجلد (`github_deploy`) ليحتوي **حصرياً** على الملفات المطلوبة للتشغيل على الإنترنت ومشاركتها عبر **GitHub Pages**، مع الالتزام التام بالمبادئ الآتية:

---

### 🌟 الميزات والمواصفات السحابية 100%:
1. **بدون أي تخزين محلي (Zero Local Cache)**:
   - تم إلغاء كافة ملفات البيانات الثابتة الضخمة (`personnel_touggourt.js` بحجم 2.3 ميغابايت، `institutions_touggourt.js`، و`cf_photos_map.js`).
   - تم إلغاء التخزين المؤقت المحلي (`localStorage` و `localforage` للبيانات) لمنع أي تضارب أو لبس بين الكاش القديم والبيانات الحقيقية في قاعدة البيانات.
   - كافة الاستعلامات والتعديلات تجلب وتحفظ مباشرة على خوادم Google Firebase السحابية وخوادم Cloudflare R2 فائقة السرعة.

2. **فصل وعزل المشاريع وقواعد البيانات (Strict Separation)**:
   - **مشروع القاعدة الأساسية (`base-touggourt`)**: مخصص **حصرياً** لكولكشن موظفي الولاية الأساسيين (`personnel` - 9,074 موظفاً) للقراءة والاستعلام الأساسي دون أي تعديل أو مساس به.
   - **مشروع نظام البطاقة (`card-touggourt`)**: مخصص لكافة كولكشونات البطاقة المهنية:
     - `employees_modified`: لحفظ التعديلات، الحركات بين المؤسسات، والصور المرفوعة من المدراء.
     - `card_global_settings`: للإعدادات المركزية، العام الدراسي، وخريطة الترقيم المعتمد.
     - `institutions_activity`: لتسجيل أوقات دخول ونشاطات المدراء.
     - `config`: لكلمات المرور والإعدادات الإدارية.

3. **مزامنة الصور اللحظية الفورية (Real-Time Live Sync)**:
   - بمجرد قيام أي مدير مؤسسة برفع أو قص صورة موظف عبر أداة القص المتطورة في `card.html`، يتم رفعها إلى Cloudflare R2 وحفظ الرابط في `employees_modified` بمشروع `card-touggourt`.
   - تنعكس الصورة فوراً (في أجزاء من الثانية) على شاشة المديرية `dashboard_card.html` عبر مستمع فايربيز اللحظي (`onSnapshot`)، وتتحول حالة المؤسسة إلى علامة الصح الخضراء، وتحدث العدادات دون الحاجة لإعادة تحميل الصفحة.

4. **معالجة الرقم الصحيح (9,074 موظفاً)**:
   - تم التخلص نهائياً من الرقم القديم 9,055 الناتج عن الملف الثابت السابق، وأصبح النظام يقرأ ويعتمد العدد الحقيقي والمؤكد في قاعدة البيانات السحابية (9,074 موظفاً).

### 🚀 خطوات الرفع والنشر على GitHub Pages:

#### الخطوة 1: تهيئة مستودع Git داخل المجلد
افتح موجه الأوامر (PowerShell أو Terminal) داخل المجلد `github_deploy` ونفذ الأوامر التالية:
```bash
cd "d:\card 2\github_deploy"
git init
git add .
git commit -m "Initial commit: 100% cloud-native card system"
```

#### الخطوة 2: ربط المستودع بموقع GitHub
قم بإنشاء مستودع جديد على حسابك في GitHub (مثلاً باسم `card-system`)، ثم نفذ:
```bash
git branch -M main
git remote add origin https://github.com/USERNAME/card-system.git
git push -u origin main
```
*(استبدل `USERNAME` باسم حسابك على GitHub)*

#### الخطوة 3: تفعيل الموقع (GitHub Pages)
1. في صفحة المستودع على GitHub، اضغط على **Settings** (الإعدادات).
2. من القائمة الجانبية، اختر **Pages**.
3. تحت خيار **Build and deployment -> Source**، اختر: `Deploy from a branch`.
4. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
5. بعد دقيقة واحدة، سيظهر لك رابط موقعك الرسمي الذي يعمل مباشرة عبر الإنترنت 24/7!
